## 二、MECE 优化方案

### 2.1 优化原则

1. **互斥性 (Mutually Exclusive)**
   - 每个功能有明确的边界，不重叠
   - 按钮、菜单项、面板之间功能不冲突

2. **穷尽性 (Collectively Exhaustive)**
   - 所有用户场景都有对应功能
   - 不存在功能死角

3. **层次清晰 (Layer Clarity)**
   - 按使用频率分层：高频 → 低频
   - 按重要性分层：核心 → 辅助

4. **渐进披露 (Progressive Disclosure)**
   - 默认显示核心功能
   - 高级功能通过展开/下拉访问

### 2.2 UnifiedCanvasToolbar 优化方案

#### MECE 分层设计

```
┌────────────────────────────────────────────────────────────────────┐
│ L1 状态区 (始终可见)                                                │
│   [节点:12] [连线:8] [层级布局] [100%]              ← 紧凑信息  │
├────────────────────────────────────────────────────────────────────┤
│ L2 搜索区 (可折叠)                                                  │
│   [🔍 搜索实体... /] [类型▼]                     ← 增强搜索   │
├────────────────────────────────────────────────────────────────────┤
│ L3 核心操作 (高频操作)                                              │
│   [+实体] [↔关系] [↩撤销] [↪重做] [🎨布局▼] [⟳重排]             │
│                                                      ← 按钮增大   │
├────────────────────────────────────────────────────────────────────┤
│ L4 视图控制 (中频操作)                                              │
│   [🔍-] [100%] [🔍+] [|] [▣适应] [⟲重置] [|] [⊞网格] [🗺地图]   │
├────────────────────────────────────────────────────────────────────┤
│ L5 状态切换 (模式切换)                                              │
│   [👁聚焦] [🔒锁定] [🔓解锁] [|] [👁只读] [|] [⌨帮助]            │
├────────────────────────────────────────────────────────────────────┤
│ L6 高级操作 (⚙折叠菜单)                                            │
│   DDL生成 | CTE编译 | 导入表 | 反向工程 | 导出 | 预设保存           │
└────────────────────────────────────────────────────────────────────┘
```

#### 具体优化

1. **响应式改进**
   - 断点1 (>1400px): 全部显示
   - 断点2 (1024-1400px): 合并部分按钮
   - 断点3 (<1024px): 工具栏折叠为图标模式

2. **批量选择指示器优化**
   - 移至 L1 状态区，显示更醒目
   - 添加快速操作按钮（全选/反选/清空）

3. **布局预设快速访问**
   - 添加快捷按钮直接访问最近使用的预设
   - 支持拖拽排序预设顺序

### 2.3 OntologyNode 优化方案

#### 节点状态设计

```
┌─────────────────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← 顶部装饰条（类型色）
├─────────────────────────────────────────┤
│ [🔒] [📊] 节点名称            [操作▾] │ ← 头部（锁定+类型+菜单）
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────────────────────────────┐   │
│  │ key1: value1                   │   │ ← 属性区域（可展开）
│  │ key2: value2                   │   │
│  │ [▶展开 3 more...]              │   │
│  └─────────────────────────────────┘   │
│                                         │
├─────────────────────────────────────────┤
│ [用户类型]  ↑5 ↓3  [●当前]              │ ← 底部（类型+连接数+状态）
├─────────────────────────────────────────┤
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │ ← 路径追踪条（动态）
```

#### 具体优化

1. **动画优化**
   - 使用 `transform` 代替高度变化
   - 添加 `will-change` 提示浏览器优化
   - 限制动画元素数量

2. **紧凑模式增强**
   - 显示节点类型图标
   - 显示简要属性（前3个字符）
   - 添加连接数指示

3. **路径追踪视觉效果**
   - 动态脉冲动画
   - 节点发光效果
   - 路径流动效果

   - 属性: 添加/删除/替换
   - 导出: JSON/CSV/复制

3. **快速操作按钮**
   - 批量删除: 一键删除选中节点
   - 批量复制: 复制为新节点

## 四、验收标准

1. **功能完整性**: 所有 P1/P2 痛点已解决
2. **性能指标**: 
   - 工具栏响应 < 16ms
   - 搜索响应 < 100ms
   - 动画帧率 ≥ 60fps
3. **用户体验**: 无功能死角，操作步骤 ≤ 3步
4. **代码质量**: MECE 原则遵循，无功能重叠
