## 实际行为

- 配置读取和写入校验筛选项、组件设置、查询规格、图表必需字段及几何范围。`y+h` 最大为 10000。错误指出字段或实例位置，非法原记录保留并隔离。
- 重叠布局自动整理：按原 y/x/列表顺序处理，保持组件身份、查询引用、x/w/h 和原列表顺序，只将发生碰撞的组件向下移动。再次打开不重复整理。
- 每个视图保留最近一次自动整理前的完整原始 JSON 备份。先提交备份，再保存整理结果；任何一步失败均不伪报成功。读取修复与用户编辑共用同视图写入队列，并在锁内重新读取，避免用旧快照覆盖新编辑。
- 在“视图设置 → 恢复整理前配置”恢复完整配置。已恢复的重叠几何使用临时单列安全展示，数据库中的原坐标保留；相同几何不会在改名或解锁时立即再次被整理。之后可手动编辑布局。此恢复会恢复备份中的完整视图定义，而非只恢复坐标。
- 首页布局沿用桌面 12 列、容器不足 960px 时单列的规则；窗口、筛选、查询结果和主题变化均不保存展示坐标。旧的数据驱动阅读重排函数与组件内容尺寸回调已移除，其他页面仍使用的展示尺寸工具保留。
- 每个组件最多一个执行中任务及一个可替换的最新待执行任务。连续刷新合并；作用域变化立即清除不适用的结果，旧响应不能覆盖新结果，卸载清除待执行任务。
- 共享查询缓存包含数据库、Schema、SQL/参数、页码、数据集版本及工作台修订。执行中的相同查询被复用，强制刷新也不会复制同一执行中请求；一个订阅者失效不影响仍有效的订阅者。
- 批量查询进入连接队列时以及各步骤开始前检查有效性，跳过过期工作。界面超时不释放连接；组件等待底层操作真正结束后才启动后续任务。没有添加全局取消或强制中断其他功能查询。
- 自动刷新在页面隐藏时暂停，恢复可见时刷新一次并重新计时。
- 本地诊断扩展查询/尺寸阶段、构建版本、耗时、队列等待和容器尺寸，仍只保留最近 50 条；不采集 SQL、参数值、业务行或堆栈。已有单组件渲染隔离与重试继续使用。
- 首页显示源码构建标识，其他页面可从“关于 DuckDB Studio”核对。标识包含未提交源码的摘要。入口移除外部字体样式依赖，使用项目内置 JetBrains Mono 及系统字体。
- 浏览器验收使用独立 Vite 缓存，并限定真实入口扫描，避免和日常开发服务的依赖缓存混用。本机验收请求直连本机地址。

## 日常检查

```powershell
node scripts/prepare-dashboard-baseline.mjs
pnpm typecheck
pnpm test:run
pnpm exec playwright install chromium
pnpm test:dashboard:browser
pnpm test:home:browser
pnpm build
```

两个浏览器脚本各自启动独立服务和浏览器上下文，默认端口为 5186、5188；可用 `DASHBOARD_BASE_URL` 指向已经启动的验收服务。最终验收时冻结源码，并避免同时构建导致开发服务重载；若有并行开发，使用隔离工作区副本。

发生故障时保存版本、触发步骤、原配置、截图和诊断 JSON，先分清查询、渲染、尺寸、配置或保存问题。针对原输入建立失败断言，再做局部修复。布局修改必须确认筛选/视口不会写回坐标；存储修改必须检查事务失败、重载、并发及数据库隔离；查询修改必须检查共享订阅、过期请求和实际连接生命周期。
