# 透视表体验实施与验收

日期：2026-10-14。对应计划：`../pivot-experience-plan-20261014.md`。

## 已实施

- 保留全局导航，将「透视聚合」改名「透视表」。
- 数据表与成功执行的只读 SQL 结果均可进入同一个透视编辑器。
- 复用并提取当前数据集解析能力，保留库、Schema、已执行查询、已应用来源筛选和唯一键检查；查询来源不要求存在实体表。
- 行、列、值、筛选四区；桌面配置与结果分栏，配置可折叠；行列互换保留日期粒度和其他设置。
- 默认记录数，不自动加总未知数值或编号；多度量可保存、切换展示；金额边际汇总要求单位隔离。
- 来源与追加筛选分开展示。Top N 明确限制的是展示的行列组合，边际汇总来自全部符合条件的来源。
- 平均、去重数等边际汇总由统一 SQL 编译器从来源重新计算；交叉表渲染器消费结果，不相加各单元格推算总计。
- 汇总单元格打开明细抽屉，包含来源、追加筛选、单位和行列条件；支持日期分组、空值、每页 50 条和下一页探测。
- 抽屉复用既有焦点管理；Escape 关闭后返回触发单元格。
- 保存完整版本化配置，支持更新、另存为、保存并加入首页、会话草稿和放弃修改。
- 待计算与旧请求结果不能保存或导出；计算失败保留配置，可重试；来源作用域漂移明确报错。
- 首页从同一分析 ID 读取最新定义，返回透视编辑器；更新不复制原分析或原卡片。
- 原 SQL-only 分析保留查看路径；字段被删除时可打开保存配置并修复绑定，不尝试凭 SQL 推断表单。
- 临时内存库明确提示保存生命周期；持久库已验证刷新后的恢复。

## 集成修复

1. 首页原先按是否存在有记录的实体表决定是否展示工作台，会隐藏 SQL-only 分析卡片。现在已有卡片的工作台可正常显示，包括来源失败时的说明。
2. 统一来源解析器曾把 `IS NOT DISTINCT FROM pr.field` 中的 `FROM` 当作来源表。已排除该比较运算符，并加入回归测试；保留空值安全的透视边际连接。
3. 首页单行分组透视的空列绑定原先可能回退到度量字段，现保留显式空列。
4. 共享目录生成的 `output` 备份被类型检查和测试扫描，导致备份引用报错及测试重复。已将该产物目录排除，保留全部备份和源码测试。

## 真实浏览器验证

使用 Playwright CLI 的独立浏览器会话，访问实际应用与实际 DuckDB WASM。没有连接或修改用户正在使用的浏览器数据库。

### SQL → 透视 → 首页 → 编辑

从真实 `duckdb_functions()` 目录读取函数类型、返回类型和参数数量。完成查询后从结果区进入透视，设置行列和平均值度量，保存到 OPFS 持久库并加入首页。

已验证：

- SQL 结果来源不受当前结果页限制；即使没有实体表也能打开透视并显示首页卡片。
- 行列互换、多个度量、平均值切换、单元格明细和分页。
- BIGINT 聚合函数单元格共 84 条，明细第一页 1–50，第二页 51–84。
- Escape 关闭明细后焦点回到原单元格。
- 首页全屏查看与「编辑透视表」。
- 返回编辑恢复行列、平均值聚合与当前展示度量；追加参数数量筛选后保存，原卡片更新且仍只有一个引用。
- 刷新浏览器后，持久库、卡片、完整配置和追加筛选仍可恢复；最终截图在重新计算成功后取得。
- 1366×900 与 768×900：配置区与结果区可操作，窄屏折叠配置后没有页面整体横向溢出，交叉表内部可横向滚动。

### 已筛选表 → 透视 → 明细

仅在独立 QA 浏览器的持久库，用真实函数目录派生 `pivot_qa_functions` 测试表。通过数据浏览界面应用 `function_type = 'aggregate'`，点击透视入口，确认来源 SQL 继承条件，结果与明细均没有其他类型记录。未在产品初始化或用户数据库中添加此表。

### 数据库计算边界

只读 VALUES 查询作为验算夹具，不创建业务表或产品默认数据。真实执行确认：

- 总平均值为 250 / 6，N 分组平均值为 140 / 3。
- 客户去重总数为 4，N 分组去重数为 2。
- 空值分组与文字「—」分开显示。
- 月份和空值行列明细准确。
- Top 2 展示限制不改变来源总计。
- 跨 Schema 来源被拒绝。
