# 工作区品质提升 · 第三轮 · 2026-10-16

本轮对真实可视化资产的浏览、比较、专注查看与图片交付进行多轮检查、修改和重放。所有资产继续引用原查询与当前数据库结果；没有新增模拟业务数据。

## 完成的改进

- 可视化资产页重新梳理标题、说明、统计与操作层级，减少重复彩色徽标。
- 新增列表展示，与画廊共享同一套搜索、分类、来源和类型筛选。列表展示名称、来源、类型、查询结果行数及固定状态，不挂载图表 canvas。列表模式仍会运行原有数据查询；本轮没有宣称减少查询次数或完成大规模性能优化。
- 展示方式保存在浏览器，页面往返后恢复。空搜索可一键重置筛选；查询失败明确显示失败，不伪装成零行。列表的“结果行”是查询返回行数，例如 COUNT 查询返回一行，其中的业务计数可能为 25。
- 列表与画廊均可进入专注查看。窗口保持键盘焦点，Escape 返回触发按钮；保留原有 SQL、来源、血缘、固定、编辑、删除与下载行为。数据库切换立即关闭旧资产窗口。
- 专注窗口与背景卡片使用独立导出容器标识，避免导出错误实例。
- 手机上的来源和类型筛选按需展开，常用分类与搜索保持可见；次要标题栏动作收为有名称的图标按钮。修正标题被截断的问题，并增加完整标题与边界检查。
- 图片导出副本去掉操作控件和内阴影，保留标题、来源与图表。导出前完成 Chart.js 动画，避免抓取柱子尚在移动的中间帧。最终实际 PNG 的柱高与 15、10 的结果值一致。
- 柱内标签根据实际填充色和背景选择黑或白，柱外标签仍使用页面文字色。默认调色板在两种背景下通过至少 4.5:1 的对比度测试；包含常用透明填充的处理，不将其等同于全部自定义渐变或全站无障碍认证。

## 自检中修正的失败与问题

- 初始开发服务未运行，隔离启动 5197 验收服务后重放；不将连接失败计为产品缺陷。
- 验收脚本曾错误地按 `aria-label` 寻找使用 `aria-labelledby` 命名的窗口；修正检查后确认固定与取消固定均真实完成。
- 生产导入会继承当前表的筛选，验收已明确选择全部来源后比较全量资产，避免把不同范围的资产数混作同一口径。
- 旧导航契约测试仍寻找前两轮已替换的空首页文案。改为等待真实导入按钮，保留后续元数据、明细与跨模块导航断言，最终通过。
- 页面边界通过后，截图仍暴露手机标题截断，已修正样式优先级并增加标题检查。
- PNG 文件存在不代表导出正确。实际图片复核发现阴影色块、操作控件和动画中间帧，逐项修正并重新导出；最终文件经过再次查看。
