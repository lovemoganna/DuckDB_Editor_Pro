## 二、 P0 补全规格：多级行维度、层级小计与展示增强

### 1. 数据模型升级与向下兼容
* `PivotDefinition` 升级支持 `rows: PivotDimension[]`（多行维度列表），同时保留对原有单数 `row: PivotDimension` 的无缝读写兼容（若旧记录仅有 `row`，自动标准化为 `rows: [row]`）。
* 行维度支持添加多个字段、上移/下移调整层级顺序、删除维度字段。
* 支持多级行层级标签展示与缩进样式。

### 2. 行列小计与总计规范
* 支持计算父级行维度的小计（Subtotal），小计使用独立的原生计算结果，去重计数与平均值不直接相加。
* 保持来源总计（Grand Total）不受前端查找和分页影响。

### 3. 空值与截断显示
* 增加空单元格配置项（默认显示 `—`，支持配置为 `0` 或 `(空)`）。
* 增加明确的展示组数截断提示，告知用户当前处于 Top N 展示，总计仍然基于全量数据。

## 三、 P1 补全规格：双表关联透视与配置管理

### 1. 双表关联透视（Dual-Table Join）
* **入口**：透视编辑器来源区域提供「关联数据表」向导。
* **配置项**：
  - 主表（当前表）与从表（选择同库内其他数据表）。
  - 关联类型：LEFT JOIN（默认）、INNER JOIN。
  - 关联键配对：主表关联键 = 从表关联键。
  - 智能推荐：自动根据字段名同名或 `_id` 匹配推荐关联键。
* **数据膨胀检查（Fan-Out Risk）**：
  - 检查从表关联键在从表中的唯一性。
  - 若从表存在重复键（1:N 关系），弹出风险警示条：“从表关联键非唯一，存在 1:N 数据膨胀风险，度量求和可能被放大，建议检查关联关系或使用去重计数”。
* **合并字段与 SQL 穿透**：
  - 双表字段统一加表名前缀并入字段目录供拖拽透视。
  - 实时编译为标准 DuckDB JOIN SQL，可下发执行并在 SQL 工作台展开。

### 2. 透视配置管理抽屉
* 透视工作台顶部提供「已保存分析模板」快速抽屉。
* 支持直接在透视工作台内查看当前数据库下的透视方案列表，支持快速载入、重命名和删除。
