# 首页精简与图表空间修复记录

实施日期：2026-10-07 至 2026-10-08。保留 DuckDB、Chart.js、现有 IDE 风格与存储类型；没有批量迁移用户看板。

## 修复内容

| 问题 | 修复 |
| --- | --- |
| 旧看板允许统计图落入约 160–200px 宽、128px 高的小格 | 浏览模式按容器宽度生成临时少列布局，统计卡片包含标题、绘图区、图例和页脚预算；窄屏单列 |
| 窗口断点无法反映侧栏和面板实际占用 | 共享容器监听同时测量宽、高，处理高度变化及隐藏后重新显示 |
| 编辑画布过窄 | 保留 12 列，画布至少 1456px，在功能区域内横向滚动；指标、统计图、表格采用不同最小尺寸 |
| 图表默认尺寸过小 | 新统计组件默认 6×7；指标卡保留较紧凑尺寸；现有保存布局不迁移 |
| 长类别、系列挤在固定画布内 | 共享空间计算扩大内部画布，类别换行，坐标文字默认 12px；保留类别及数据点 |
| 饼图、环图图例占据绘图区，极小扇区无法辨认 | 独立完整分类数值列表，支持可见性切换；保留完整名称及小占比精度；环图合计进入卡片摘要 |
| KPI、大数值、宽表截断 | 指标按自身宽度排列、数值换行；表格保留完整值、列宽、排序和滚动 |
| 编辑预览高度依赖不明确，窄屏按钮挤成竖排 | 可滚动配置区域、明确预览最低高度、容器内换行与不折断的操作按钮 |
| 首页入口及说明重复 | 单一导入、添加分析入口；结果前置；来源 SQL、技术信息、质量检查和低频设置进入对应面板 |
| 首次首页堆叠固定指标 | 从真实发现结果中选择当前数据集的记录数、分布、趋势及适用汇总；已初始化的空视图不补回删除组件 |
| 图片只导出可见部分或遗漏外部图例 | 导出克隆中展开绘图区、图例和分类数值列表，不改变当前界面 |

布局计算仅用于显示，不修改查询、聚合、排序或结果数量。已有 SQL Top N、发现查询的 LIMIT 和用户显示选项继续生效。
