# SQL 流程图 UI、功能与交互审查

审查日期：2026-10-02。沿用项目现有主题变量、字体、按钮与面板语言，在当前工作区版本上修复；没有重建视觉体系。使用 Product Design audit 流程，证据来自本次源码检查、组件回归与应用内浏览器实际页面。

## MECE 范围与结果

按操作职责划分，节点内部各算子参数归入配置，运行后的输出归入结果；避免把同一执行状态分散成多套规则。

| 范围 | 覆盖组件 / 链路 | 问题与修复 |
|---|---|---|
| 入口与模式 | 独立画布、SQL 分屏、catalog 深链 | SQL 内容原来会覆盖用户模式选择。显式模式保持独立，分屏持续由当前 SQL 驱动；模式改变使在途 SQL 同步失效。 |
| 导航与操作 | 模式胶囊、关联查询、工具菜单、画布工具 | 顶栏允许换行，菜单不再被横向滚动容器裁切；只在自由编排展示添加算子，SQL/血缘禁止手工连线、拖入与删除快捷键。 |
| 资产与编排 | AssetSidebar、NodeConfig | 算子卡片支持键盘操作；补齐数据来源、SQL、连接条件、分组及聚合、结果上限、导出参数。Schema 的真实字段结构沿用下方清单，不伪造检查功能。 |
| 图形与定位 | Node、Edge、缩放、小地图、fitView | 缩放标签直接订阅视口；图成员或模式变化时自动适配，普通字段修改不重置视口。自动适配最大 100%，保留用户主动放大。节点几何和左右端口协议不变。 |
| 属性与诊断 | Inspector 配置、预览、记录、EXPLAIN、SQL 回跳 | 查看预览不再隐式执行查询。删除样本量冒充总行数、固定耗时及错误成功状态；修复节点切换残留 EXPLAIN、异步响应串节点及复制失败反馈。 |
| 执行与结果 | BottomDrawer、日志、节点历史、采样表 | 状态显示真实执行中/待运行；正确展示零行成功结果、NULL、最多 50 行与总行数。配置修改后的旧数据明确提示需重跑。 |
| 布局与无障碍 | 上述组件、SQL 流图分隔条 | 正文 11px、表格 10px，8px 微标签提升至 10px；面板内边距收敛。统一焦点与禁用状态，抽屉及分屏支持键盘调整；非法缓存比例或高度恢复默认值。 |
| 主题与基础元素 | 模块共享样式与主题变量 | 主按钮浅色白字、深色暗字均有可读对比；菜单使用真实不透明主题背景；表格、链接、代码、引用、分割线、图片均在模块作用域规范。当前模块无独立图片/富文本内容，未添加无关功能。 |

另外，SQL 推断回退路径中的写死成本比例不再展示为真实性能指标。缺少查询证据的行数、耗时保持未知，不填充演示数据。

## 本次浏览器链路与截图

1. 当前 SQL 流图：发现缺失数据源的真实 Catalog Error，错误节点、诊断与返回 SQL 均有入口。健康度：恢复路径可用；查询本身仍须使用存在的数据表。[深色截图](sql-flow-audit-20261002/01-sql-dark.png)。
2. 属性诊断：节点配置、数据预览、执行记录分区完整。健康度：复制、定位、回编辑器入口可用。[深色](sql-flow-audit-20261002/02-inspector-dark.png)、[浅色](sql-flow-audit-20261002/03-inspector-light.png)。这两张记录的是本次中途审查状态。
3. 全库血缘：读取当前数据库实际 13 个表，切换后保持 catalog 模式。健康度：修复模式回跳；本次数据库无表间依赖边。[审查截图](sql-flow-audit-20261002/04-catalog-light.png)，该截图暴露的视口未适配问题随后已修复。
4. 自由编排配置：真实数据表显示格式及来源配置入口。健康度：新增表单连接真实工作流状态，修改会使下游需重跑。[配置截图](sql-flow-audit-20261002/05-config-light.png)。
5. 节点数据预览：当前实际表 25 行、13 列；预览保留字段类型并区分 NULL。健康度：可读、横向滚动可用，无隐式级联执行。[预览截图](sql-flow-audit-20261002/06-preview-light.png)。
6. 控制台采样：展示数量与实际总量对应。健康度：日志、历史、采样切换可用，抽屉不挤压至丢失画布。[控制台截图](sql-flow-audit-20261002/07-console-light.png)。
7. SQL 分屏：使用当前工作台实际查询，展示扫描、过滤、聚合、结果。健康度：编辑器与流图保持联动，窄屏顶栏换行，主控制台由工作台负责；真实只读 SQL 执行成功，返回 1 行，执行后再适配视口。[960px 浅色](sql-flow-audit-20261002/08-split-light-960.png)、[960px 深色](sql-flow-audit-20261002/09-split-dark-960.png)。

## 验证与边界

- 10 个相关测试文件、111 项通过，覆盖流程图、边协议、编译、执行、状态、SQL 解析和 SQL 分屏。
- 最后布局修改后，画布、面板、SQL 工作台 3 个文件、33 项组件回归通过。
- 类型检查与最终生产构建均通过（最终构建 3 分 47 秒）。日志保存在 sql-flow-build-final.log；构建包含依赖体积与 DuckDB worker eval 的现有警告。
- 浏览器先遇到连接超时，恢复后完成真实页面检查。没有采用旧截图作为审查证据。
- 图片、引用、链接并非这个模块的主要内容；其基础样式已对齐，不能据此宣称不存在的子页面已实测。
- 未通过浏览器逐一执行所有导出格式、所有 JOIN/聚合组合；这些链路以相关编译执行测试补充。未做屏幕阅读器、全主题全状态或完整 WCAG 合规认证。
- 保存的截图用于局部审查，部分是修复中途状态，不能当作所有最终组件和所有视口的完整像素验收。
