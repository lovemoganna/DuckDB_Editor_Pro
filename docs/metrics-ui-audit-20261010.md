## 范围与方法

在现有未提交工作区基础上继续修复，保留现有 Monokai 主题、布局语言和共用 Workbench 组件。没有提交或推送代码。

按相互独立的检查轴组织：页面职责、对象生命周期、视觉元素、交互状态、主题与屏幕尺寸。计算原语、分析方法、业务领域、治理属性仍是独立分类轴，未将它们合并为互斥业务类别，也未新增重复分析引擎。

## 本次修复

| 问题 | 修复 |
|---|---|
| 编辑器和方法向导的原生选择框脱离现有体系 | 全部接入 FormSelect，保留多选区域高度 |
| 模板说明正文大小与指标工作台不统一 | 正文统一到 12px；代码预览 11px；标题层级保留 |
| Portal 弹窗无法继承模块内规范 | 各弹窗显式应用 metric-surface，使用现有主题变量 |
| 焦点、禁用、复选框、代码、分割线等状态不统一 | 模块局部统一规范，未改全站主题 |
| 多表包中方法向导的显式来源被覆盖为空 | 保留模板 / 方法传入的 sourceTable，再使用单表回退 |
| 未绑定来源时无法从字段模式切换到完整 SQL | 允许进入 SQL 模式填写独立查询，完整字段定义仍保留生成 SQL |
| 编辑验证完成后可能写回已关闭或切换的弹窗 | 请求代次隔离；关闭 / 切换即失效 |
| 验证中可以继续改变待验证字段 | 字段区域锁定，按钮显示处理中状态 |
| 方法向导读取字段没有状态提示 | 补充读取中、无字段和错误提示；移除已失效的来源选择 |
| 空包可以导出却无法重新导入 | 接受显式空 metrics 数组；拒绝缺失数组和全部无效条目 |
| 文件读取期间切换数据库可能导入到错误环境 | 在读取完成时核验数据库，并补充读取失败反馈 |
| 外部来源名称和包含单引号的 URL 生成无效 SQL | 使用共用标识符与字符串引用函数；SQLite 显式 TYPE SQLITE |
| 复制外部 SQL 后延时强制关闭弹窗 | 复制保留弹窗，失败可以重试；输入改变清除复制状态 |
| 数据源执行通知暗示挂载已成功 | 明确仅发送至工作台；说明浏览器本地文件与跨域要求 |
| 手动添加来源不可见、不可移除 | 显示可移除来源标签；单来源初始草稿显式绑定 |
| 趋势分析从公式重新拼装，丢失结构化口径 | 使用现有指标编译器，保留过滤、分组和分析变换 |
| 趋势 / 对比 SQL 沿用原图表的列配置 | 同时更新图表类型、横轴与度量列 |
| 图表删除后对比选择保留过期 ID | 重载时同步选择集合，少于两项退出对比模式 |
| 图表异步操作可以并行重复触发 | 操作状态与互斥禁用；趋势 / 对比增加数据库切换检查 |
| 版本历史已保存但没有展示入口 | 在展开参数内显示变更版本、时间、字段和原值 |
| 结果预览只展示六列且展开仍看不到其他列 | 展开显示全部缓存列，并准确显示可见 / 总列数 |
| 窄屏详情工具栏溢出、标题被按钮挤压 | 操作组限制宽度并换行；窄屏卡片标题和操作分行 |
| 包搜索空状态缺少恢复入口 | 增加清除搜索；不存在的分类在数据更新后自动复位 |
| 收藏与来源选择没有可读的选中状态 | 补充 aria-pressed 和相关表单可访问名称 |

## 统一元素说明

- 字体：沿用现有 sans / mono；正文 12px，代码 11px，标题保留层级。
- 链接：沿用主题强调色，统一键盘焦点和下划线距离。
- 列表：方法规则与版本历史保持有序 / 无序语义，长内容允许换行。
- 引用、图片：当前指标主流程没有独立的引用或图片组件；局部规范提供引用边界和图片尺寸约束，没有为了覆盖清单添加无用途内容。
- 代码块、表格、分割线：采用现有背景、边框和前景变量，代码可滚动，表头使用表面色。
- 按钮、表单：沿用 ActionButton、IconButton、FormInput、FormTextarea、FormSelect、ModalShell。
- 提示：错误就地可见，异步操作有禁用 / 处理中反馈，技术验证与业务审核继续分别记录。
