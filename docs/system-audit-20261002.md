## 已有架构

入口由 App 的功能标签管理：工程（首页/数据/Schema/SQL/数据流）、分析（指标/可视化/分析/历史/审计），以及知识和 AI。重点页面实际入口可访问。原始 SQL 存 IndexedDB，导入数据库存 OPFS；业务对象与布局存当前数据库的 `__studio`，本地指标缓存按数据库隔离。共享运行时响应数据库和结构变化，统一字段模型；首页组件引用原始指标/图表/分析 ID，查询实际数据库。布局本身可保存、拖拽、缩放和重复引用，不应改回固定页面。

## 数据与对象关系

SQL 来源 → 当前数据库/Schema → 表字段模型 → 指标定义 → 图表引用 → 分析记录引用 → 首页组件引用。数值只在执行原始定义时产生，不复制到跨页面配置。完成金额、全部订单金额、余额与净流入必须区分；USD/USDT/BTC 等单位不相加；历史汇率不视为实时价格；冻结状态与历史出金的关系只标为待核对。
