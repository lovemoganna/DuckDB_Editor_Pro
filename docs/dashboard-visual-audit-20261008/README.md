## 对照 DataWind

[官方阅览说明](https://docs.volcengine.com/docs/Datawindprivatization/Dashboardviewoperation?lang=zh)将全局操作集中到右上角，图表的其他操作在悬停后通过更多入口显示。当前项目在每张卡片常驻多项图标，并重复放置分析口径和更新时间。需要保留能力，但常驻信息应服务于阅读。

DataWind 阅览截图也有较大的装饰标题，不能将它直接作为本项目提高信息密度的答案。可借鉴的是指标与趋势的主次关系、统一分析范围和按需操作。
