# 可视化模块 UI、功能与交互审查

日期：2026-10-10。原则：保留现有 Monokai 语义配色与工作台结构，优先修复系统性断点，不另建视觉体系。

## MECE 覆盖范围

| 范畴 | 页面 / 组件 | 核查内容 |
| --- | --- | --- |
| 资产发现 | VisualizationWorkbench | 来源分类、首页固定状态、表 / 类型 / 关键词筛选、指标上下文、空与错误状态 |
| 创建与编辑 | ChartBuilder、WidgetChartConfigPanel | 手动 / 指标创建、字段绑定、数值识别、公共显示规则、透视表、草稿切换、保存反馈 |
| 执行与呈现 | readQuery、公共 registry / adapter、ChartRenderer、PivotTableView | 只读查询、请求失效、查询失败与零行结果区分、数值格式、分页 / 筛选 / 排序、图例与选择状态 |
| 图表操作 | VisualizationCard、ChartDashboard | 编辑、复制 SQL、导出、删除、禁用 / 忙碌状态、键盘与触屏可达性 |
| 跨模块联动 | visualizationAssets、首页服务、LineageGraphView | 原始资产更新、SQL 保留、首页关联移除、对象引用清理、指标 / 数据 / SQL / 分析跳转 |
| 横向规范 | visualizationUi.css、现有 ModalShell / DrawerShell / FormSelect | 双主题、字号、间距、边框圆角、焦点、弹窗层级、窄屏、内容溢出 |

“指标衍生 / 即席”是来源分类；“已固定首页”是展示状态视图。继续复用现有入口，避免增加第二套资产目录。

## 本次修复

- 类型筛选接入公共注册表，补齐面积、漏斗、瀑布、直方图和组合图；将历史 counter 归入指标卡入口，避免重复选项。透视表归入数据表筛选。
- 表筛选支持带 schema、引号的标识符；补充资产 SQL 中引用的表选项，数据跳转交由现有来源导航解析跨范围标识符。
- 区分“加载中、加载失败、没有资产、筛选无匹配、查询失败、查询成功但零行”，加载失败可直接重试。
- 数据库切换清空旧资产与上下文、关闭旧弹窗；过期资产 / 数据请求不再回填。EXPLAIN 与实际查询之间增加数据库检查。
- 图表数据最多四个并发请求，已完成的卡片及时显示，避免等待最慢查询后一起出现。
- 批量生成与指标创建采用指标自身来源；多表包不再任取第一张表，SQL 指标无需人为补一个无关表。
- 从实时结果识别数值列，不再将查询第二列一律作为数值轴；无数值时使用数据表。模式切换保留手动草稿。
- 预览与保存有效性同步计算，字段绑定错误时阻止保存；保存过程中禁用配置区域和取消，保留失败时的编辑内容。
- 新建界面明确告知手动图表前 100 行的预览与保存范围；没有数据表时仍可进入有效的指标创建流程。
- 补齐透视表的展示模式、行维度、列维度、数值字段和汇总配置，复用公共渲染管线。
- 复选项改为键盘可操作的原生输入；左右轴字段使用不同可访问名称；修复显示选项每次更新重建组件导致的焦点丢失。
- 编辑 / 血缘 / 删除使用现有统一弹窗；复用焦点约束、Escape、背景关闭与焦点返回。嵌套字段抽屉只关闭顶层。
- 删除前展示影响说明；删除图表时同步移除首页组件与无 SQL 的生成引用，保留用户保存的实际 SQL。
- 资产已被移除时，编辑明确报错；跨数据库旧资产的修改在写入前拒绝。
- PNG 背景跟随当前主题，文件名过滤 Windows 不支持字符。通用图表网格导出补齐忙碌 / 失败反馈，操作按钮在键盘与触屏场景持续可见。
- 表单使用公共选择器；统一焦点、禁用、换行与窄屏布局。正文基准 12px，代码 11px，标题与数值重点层级保留。

## 元素检查

字体、链接、按钮、表单、提示和分割线沿用已有语义变量；列表 / 引用 / 代码提供局部内容规则；数据表继续使用公共筛选、排序、分页、汇总与透视呈现。图片限定容器宽度，导出图片分别检查浅色和深色背景。模块不新增无业务用途的富文本或图片页面。
