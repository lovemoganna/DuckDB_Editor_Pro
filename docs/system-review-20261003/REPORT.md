审查日期：2026-10-03 至 2026-10-04。项目：Duckdb_Manager/duckdb-editor。使用 Product Design audit 工作流，实际浏览器地址为 http://127.0.0.1:5173/DuckDB_Editor_Pro/。

## 结论与范围

保留现有 Monokai 气质、12px 主体密度和图谱几何算法，按「全局扫描 → 识别问题 → 根因定位 → 统一规则 → 最小修改 → 回归」完成本轮修复。主要问题集中在容器宽度判断、主题硬编码、元数据失败语义、SQL 数据流编译和反馈状态。本轮没有改写业务表数据，浏览器回归使用真实 OPFS 数据和 SELECT 查询；数据流执行会创建临时视图。

覆盖四个业务领域、16 个主入口，以及分析工具、知识阅读/图谱、数据网格、Schema、表预览、SQL 结果和助手菜单等子界面。这里的“正常”只表示记录的路径和状态通过，不表示每个组件的所有组合、外部服务和全部数据规模均已验证。原工作区已有大量修改，本轮未提交或覆盖其他工作。

## 已修复的共同根因

1. **实际工作区宽度与窗口宽度混用**：新增 `useContainerWidth`，供 WorkbenchShell、知识详情和图谱复用。窗口很宽但中心画布很窄时也能响应。知识阅读区保留图谱最小宽度，不足时纵向排列。
2. **持久布局直接接受任意 JSON**：校验对象、布尔值和有限数字；尺寸限制在既有范围。错误存储不再导致错误开关和异常布局。
3. **工具栏单行与固定高度**：共享 PageHeader/PanelHeader、SQL 工具栏、结果头和分页允许有序换行。结果内容最小 128px，外层允许滚动，避免短窗口换行后表格被挤至零高度。
4. **固定深色代码与局部 CSS 覆盖**：共享代码块及分组 SQL 预览跟随现有主题；整理 Copilot 表菜单/历史区域的原规则，去除 `!important` 和无差别透明子元素覆盖，保留全局焦点轮廓。
5. **图谱窄画布悬浮控件重叠**：控制面板按画布约束宽高，打开时收起冲突的悬浮入口；底部操作按最小单项宽度排列。SVG/Canvas/WebGL 元信息提取成唯一来源，几何算法保持现状。
6. **元数据一次失败导致整体丢失或显示假零值**：逐表获取真实 Schema 与行数，保留成功项；未知显示未知，真实空表显示 0；提供错误提示与刷新重试。
7. **数据流展示文本被当作 SQL**：编译前移除 `where:` 展示前缀和终止分号；fallback 过滤条件不再被截断。合成聚合节点保留原始 SQL，避免聚合退化为 `SELECT *`。
8. **成功执行仍显示“待运行”**：底部反馈由节点当前执行状态、错误和实际结果决定，包含运行中、失败、完成和部分完成。
9. **数据体检把唯一性推断显示成 PK**：徽标改为“候选键”，提示明确仅基于当前数据唯一且非空。概览的实际声明主键仍保留原 Schema 来源。
10. **旧示意功能残留**：移除未接入实际流式读取、使用固定行数/速率的休眠弹窗和状态，不影响真实查询加载状态。
11. **测试环境与真实交互脱节**：Escape 测试发送给当前焦点目标；首页测试补齐现行服务契约中的运行时/领域设置接口，未放宽业务断言。

外部 AI 输出、插件安装、破坏性删除/批量写入、所有导出文件格式、超大数据压力、复杂 CTE/多语句 fallback、全部辅助技术和逐项对比度没有完整执行验证。此次浏览器曾遇到开发热更新的动态导入错误，已有 Retry 能恢复；最终重载后入口正常，不把开发更新异常误报为业务结果。

仍有未挂载旧组件与大文件中的局部样式债务，不能把扫描到的 TODO 当作当前死入口。本轮只收敛有证据的共同根因，没有为了审查改写全部组件。后续同类规则应继续使用现有 Workbench 控件、语义变量、共享容器测量与实际执行状态；不要再次追加页面专用覆盖或展示型假状态。
