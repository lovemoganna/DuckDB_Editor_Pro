独立完成一个最小模型

不追求一次画对。先写有依据的草稿，再删除问题内容，最后用实际问题复测。

三步完成

  1. 写草稿。 从材料中记录对象、过程与角色、状态和直接关系。
  2. 做减法。 删除重复对象、错误连接、过度推断和材料未描述的过程。
  3. 用问题复测。 只沿模型找答案；发现问题只修一处，再问同一个问题。
检查对象 通过标准 常见问题
节点与连接 每一项都能指回材料 加入“现实中可能发生”的内容
同一对象 不同状态下仍只有一个身份 把“待检样品”建成第二个样品
复测答案 能沿模型连接得到且与材料一致 凭记忆替模型补答案
无法回答的问题 明确保留为未知 把“待复核”推断为“已合格”

停止条件

当前问题能正确回答、每项内容都有依据、没有重复和过度推断，就停止修改。

依据： Stanford Ontology Development 101 建议围绕使用目的建立初稿，并通过实际使用和讨论持续检查、修正。
