事实、推断、未知

只判断证据强度，不急着建模。拿不准时，宁可保留未知。

三步判断

  1. 原文直接说了吗？ 是 → 事实。
  2. 没有直说，但能指出具体线索吗？ 是 → 推断，并写明线索。
  3. 没有足够线索排除其他可能吗？ 是 → 未知，写出缺少什么。
类别 写法 自检问题
事实 “材料明确说明……” 能指出原文中的哪句话吗？
推断 “根据……，可能……” 是否保留了“可能”，并写出线索？
未知 “材料无法判断……，缺少……” 是否诚实保留了不确定性？

最常见的错误

  • 把符合常识写成材料事实。
  • 把叙述顺序直接当成因果或必要依赖。
  • 因为材料没写，就断定某件事没有发生。

依据： W3C OWL 2 Primer 说明缺失陈述不必然为假； Stanford Ontology Development 101 强调显式描述领域概念与关系。
