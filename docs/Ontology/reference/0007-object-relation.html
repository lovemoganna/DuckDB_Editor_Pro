怎样写清两个对象的关系

一条对象关系由三部分组成：左边对象、关系词、右边对象。顺序改变，意思也可能改变。

三步完成

  1. 找两个已有对象。 不要在写关系时临时创造对象。
  2. 用材料中的词连接。 关系词要能读成一句完整的话。
  3. 按原句检查方向。 从左读到右，意思必须与材料一致。
候选关系 当前判断 原因
订单7—包含—包裹B 可记录 与“订单7包含包裹B”方向一致。
包裹B—包含—订单7 不记录 关系方向被反转，意思已经改变。
包裹B—存放于—仓库1 可记录 能从左到右读回材料原句。
周姐—拥有—仓库1 不记录 材料只说“负责”，没有说“拥有”。

和角色的区别

角色：周姐在“交付包裹”过程中是交付人。
关系：周姐—负责—仓库1。

角色说明对象在一个过程里做什么；本课的关系直接连接两个对象。

依据： W3C RDF 1.1 Concepts 将关系陈述组织为主语、谓语、宾语三个部分，并用有方向的节点—连线—节点图表示。
