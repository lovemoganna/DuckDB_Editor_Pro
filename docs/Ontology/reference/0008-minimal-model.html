怎样组装最小本体模型

最小模型不是节点越少越好，而是足够表达材料，同时没有重复对象和无依据内容。

三步完成

  1. 收集已经验证的结果。 放入对象、过程、角色、状态和直接关系。
  2. 合并同一个对象。 同一对象在不同过程和状态中只保留一个身份。
  3. 逐项检查证据。 每个节点和每条连接都能指回材料，否则删除。
候选内容 当前判断 原因
对象：包裹B 保留 材料中的具体对象，多个事实都指向它。
状态：包裹B—待领取 保留 材料明确给出的交付前状态。
新对象：待领取的包裹B 删除 它把同一对象和状态误拆成了第二个包裹。
状态：包裹B—运输中 删除 材料没有提供这个状态。

完成检查

  • 每个对象只有一个身份；
  • 每个过程都有明确参与对象；
  • 角色属于过程连接；
  • 状态属于同一个对象，并标明变化前后；
  • 直接关系方向正确。

依据： Stanford Ontology Development 101 建议从粗略初稿开始，再迭代修正；具体取舍应服务于模型的使用目的。
