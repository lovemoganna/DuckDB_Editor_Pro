什么需要建成对象

对象是当前任务中需要保持身份的具体人、物或地点。它也叫“实例”。

三个判断问题

  1. 能问“是哪一个”吗？ 例如：哪名员工、哪个包裹、哪间诊室。
  2. 它会继续参加动作或发生变化吗？ 如果会，通常需要保持身份。
  3. 它只是时间、动作或状态吗？ 如果只是这些，当前先不要建成对象。
材料中的词 当前判断 原因
小林、王女士 对象 具体人物，会参与多个动作。
包裹B、仓库1 对象 具体物品或地点，需要区分身份。
上午、18:00 不是 当前只是时间信息。
交给、检查 不是 它们是动作，后续会单独学习过程。
观察状态 不是 它描述同一对象此刻怎样。

完成后的输出

只写一行对象清单，不急着分类：

对象：小林、仓库1、周姐、包裹B

依据： Stanford Ontology Development 101 将领域中的具体事物称为类的实例。本课暂时只练寻找实例，不讲类型体系。
