随手查 · 03

什么需要建成过程

过程是材料中实际发生的事情。它在一段时间内进行，并让对象参与、移动或发生变化。

先问一句

发生了什么？

三个判断问题

  1. 它真的发生了吗？ 材料要有明确陈述，不能靠常识补动作。
  2. 它会经过时间吗？ 即使很短，也会有发生前和发生后。
  3. 它让对象参与或变化了吗？ 例如进入、交付、检查、离开。
材料中的词 当前判断 原因
进入仓库、交付包裹 过程 事情发生了，并让对象参与或移动。
小林、包裹B 不是 它们是参加过程的具体对象。
上午、10:00 不是 它们说明过程何时发生。
观察状态 不是 它描述对象此刻怎样，不是正在发生的事情。
进入观察状态 过程 它描述对象从原状态变为观察状态。

完成后的输出

用动词短语写一行，不添加材料没有说过的动作：

过程：小林进入仓库；周姐交付包裹B；小林离开仓库。

依据： W3C PROV-O 将 Activity 定义为在一段时间内发生、并作用于或与实体一起发生的事情。本课程用更直白的“过程”指代这种建模对象。
