怎样记录对象状态变化

状态说明同一个对象在某个时刻或一段时间内怎样。对象没有变成两个，只是状态发生了变化。

三步完成

  1. 选中对象和过程。 明确是谁或什么发生了变化。
  2. 找过程前后的明确描述。 分别写入变化前和变化后。
  3. 没有依据就不记录。 不用常识补全材料未说明的状态。
候选内容 当前判断 原因
包裹B—待领取 变化前 材料明确说这是交付前的状态。
包裹B—已领取 变化后 材料明确说交付完成后被标记为已领取。
包裹B—运输中 不记录 材料没有提供这个状态。
交付包裹 不记录 它是发生的过程，不是持续的状态。

不要混淆

对象：包裹B
变化前：待领取
过程：交付包裹
变化后：已领取

依据： OMG Unified Modeling Language 2.5.1 中的 State 与 Transition 规范。本课把它简化为“同一对象在过程前后分别怎样”。
