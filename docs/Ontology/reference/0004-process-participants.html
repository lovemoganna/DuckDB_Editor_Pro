怎样把对象连接到过程

一次只看一个过程，把材料明确涉及的已有对象连接到它。

三步完成

  1. 圈出一个过程。 先不要同时处理整段材料。
  2. 问“这件事涉及谁或什么”。 只从已有对象清单中选择。
  3. 逐一连接。 同一个对象反复出现时，继续使用同一个对象，不要重复创建。
过程 连接的对象 不要连接
小林进入仓库1 小林、仓库1 周姐、包裹B
周姐交付包裹B给小林 周姐、包裹B、小林 材料未提及的对象
小林离开仓库 小林、仓库1 包裹B，因为材料没有说它也离开

当前边界

本课只判断“连不连接”。对象在过程中具体承担什么作用，下一课再命名。

依据： W3C PROV-O 说明 Activity 会作用于实体或与实体一起发生，并允许把 Agent 与 Activity 关联。本课将它简化为初学者可执行的“过程—对象”连接。
