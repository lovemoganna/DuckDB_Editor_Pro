# 运行清单：家庭聚餐本体培训

## 输入快照

### source_material

> 一顿家常饭。家里四个人：我、我爸、我妈、我妻子。中午，我妈在家做了一道茄子；我骑车六里地去川菜馆，买了西红柿牛腩、茄子炒长豆角两道菜，骑车回家，全家一起吃饭。

### modeling_scope

分析家庭成员通过制作或购买取得食物，并共同参与一次用餐的对象、过程、角色、状态和关系。配送、付款、营养、库存和一般家庭规则不在范围内。

### acceptance_questions

| ID | 建模前冻结的问题 |
| --- | --- |
| CQ-01 | 案例中有哪些人物、地点、菜品和过程？ |
| CQ-02 | 同名或近似名称的菜品是否为同一实例？ |
| CQ-03 | 每道菜通过制作还是购买进入案例？ |
| CQ-04 | 谁在什么过程中承担什么角色？ |
| CQ-05 | 同一对象发生了哪些状态变化？ |
| CQ-06 | 过程之间是先后、依赖、并发还是汇聚？ |
| CQ-07 | 哪些结论是事实、推断或未知？ |
| CQ-08 | 新案例可以直接复用、需要扩展还是超出范围？ |

### blind_case

R1：

> 晚上，我回到家时，我爸已经做好一道茄子，我妻子正在做另一道茄子。过了一会儿，我、我爸和我妻子一起吃晚饭。

R1 与源案例结构不同：它没有购买过程，包含两个同名菜品实例、两个制作过程和一个明确的过程重叠。R1 不属于源材料，Step 1、Step 2 不得读取。

以下答案在 Step 2 开始前冻结，测试期间不得修改。

| CQ ID | 预期答案 |
