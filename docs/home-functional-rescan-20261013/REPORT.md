## 已修复项

### R1 旧视图异步保存结果覆盖当前视图

- 类型/级别：缺陷，一级。影响较高，局部修复。
- 位置：`components/Dashboard/Home/WorkspaceObjects.tsx:38`、`:107`、`:116`及其视图操作回调。
- 现象：视图A执行加入分析期间切到B，A完成后仍向上调用onChange(A)，把当前视图切回A；旧操作的提示也可能出现在新视图。
- 证据：修改前副本的handleAddObject完成后无条件onChange(next)；`red-tests.txt`中“does not replace the current view…”失败，收到board1回调。现成参考：HomeBoardCanvas的currentView/publish已有归属检查。
- 根因：加载对象列表有请求生命周期保护，但异步写入完成后的界面发布没有视图/数据库归属保护。
- 修改前→后：无条件发布→以发起时数据库和视图ID核对当前归属，组件卸载后也不发布；同一组件内切换、创建、重命名、复制与资金总览复用publish；旧作用域错误/成功提示及名称/视图列表更新被阻止。原服务写入仍针对原目标，不改变已授权保存的数据内容或存储规则。
- 修改记录：changes.diff中WorkspaceObjects块；before中对应原文件。
- 验证方法：`components/Dashboard/Home/WorkspaceObjects.test.tsx:21`，延迟加入结果、重渲染为另一视图、再完成旧请求，断言onChange不被调用；同文件原有加载失败重试、重叠读取、不可用对象、引用标记、搜索测试回归。
- 验证结果：首轮9项专项测试通过（round1-tests.txt）；后续纳入最终关联回归。竞态通过组件运行测试控制时序，未在用户真实库制造写入竞态。

### R2 布局锁定保存期间可重复提交

- 类型/级别：缺陷，一级。修复成本低。
- 位置：`components/Dashboard/Home/HomeBoardCanvas.tsx:61`、`:139`、`:241`。
- 现象：编辑布局/完成编辑按钮在保存期间仍可点；服务对最新状态取反，连续请求可反复翻转锁定状态。
- 证据：原handleToggleLayoutLock只有dashboard存在性检查；原按钮无disabled/loading；dbService.updateDashboard串行应用`current.layoutLocked === false`。red-tests.txt新增用例在toBeDisabled断言失败。
- 根因：持久化更新已串行，但用户操作没有防重入或保存中的禁用状态。
- 修改前→后：每次点击直接排队→ref同步拒绝重入，按钮沿用loading/disabled，finally释放，失败仍沿用原错误提示并允许重试。没有调整布局坐标、默认锁定规则或取反逻辑。
- 修改记录：changes.diff中HomeBoardCanvas块；before中对应原文件。
- 验证方法：`components/Dashboard/Home/HomeBoardCanvas.audit.test.tsx:22`，延迟存储，验证按钮禁用与仅一次写入；拒绝后按钮恢复，重试正常调用；已有生命周期、布局尺寸与锁定回归共同检查。
- 验证结果：首轮专项通过；失败和重入为组件运行测试注入，未改变实库布局。

### R3 图表字段配置忽略保存结果

- 类型/级别：缺陷，一级。错误反馈和防重入按一个异步保存根因合并。
- 位置：`components/DashboardWidget.tsx:694`；`components/Dashboard/WidgetChartConfigPanel.tsx:27`、`:65`。

- 根因：异步结果没有传回当前配置面板，面板没有完整保存生命周期。
- 修改前→后：丢弃结果并重复触发→保留现有回调返回的实际Promise，面板等待完成；ref拒绝重入、按钮显示保存中；失败时alert说明“配置未保存”，保留草稿并允许再次应用；成功继续使用原Widget保存与关闭流程。现有props声明、服务契约、图表字段和计算口径均未修改。
- 修改记录：changes.diff中WidgetChartConfigPanel及DashboardWidget块；before中对应原文件。
- 验证方法：WidgetChartConfigPanel.test.tsx新增延迟保存、拒绝、草稿保留、重试用例；DashboardWidget.requests.test.tsx:19通过真实组件连接到拒绝的onSettingsChange，验证错误出现在配置抽屉且面板未关闭。原字段映射、透视、直方图、单位、KPI配置用例回归。
