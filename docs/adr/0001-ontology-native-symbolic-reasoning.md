# ADR 0001: Ontology 原生符号推演作为组合推演核心

- 状态：Accepted
- 日期：2026-08-08

## 背景

旧组合推演维护了一套独立的特征、规则、结局和固定风控样本目录。它只通过对象类型编号与 Ontology 松散关联，不能基于当前对象属性、实际关系和结构化动作回答“为什么成立、还缺什么、改变什么会不同”。

## 决策

组合推演以当前 Ontology 的不可变快照为唯一世界来源，并采用三值符号逻辑：

- 类型变量规则绑定真实对象实例；
- 条件读取真实属性、关系和派生结论；
- 假设与动作只改变隔离世界；
- 冲突产生可解释分支，优先级仅在明确配置时裁决；
- 每个结果保留事实、绑定、规则版本和效果路径；
- 统计概率退出主流程，只能作为未来显式配置的数据证据适配器。

## 后果

- 没有结构化规则的 Ontology 只能回答当前已存在的事实，系统不会从名称或描述中猜测规则。
- 属性、规则和动作定义成为 Ontology 导入导出的一部分。
- 旧统计目录和数据表不删除，以兼容历史导出和未来证据适配，但不再驱动组合推演界面。
- 推演运行保存原始快照和场景，重放不依赖当前 Ontology 状态。
