# UI 与交互一致性巡检（2026-10-02）

范围：首页、指标、可视化、关联分析，以及共享导航、表单、图表和弹层。保留现有 Monokai 工作台风格、数据库和已保存编排。

## 修改前发现（按互斥类别归档）

| 类别 | 确认问题 | 修复方向 |
|---|---|---|
| 视觉语义 | 全局 `!important` 抹平按钮主次、强调边框、卡片背景 | 删除跨组件强制覆盖，恢复已有组件规范 |
| 信息组织 | SQL 说明、视图创建和看板说明常驻，占据首屏 | 来源保持可见，低频管理与说明按需展开 |
| 操作流程 | 内容库展开挤走仪表盘；加入对象没有反馈 | 复用抽屉，保留重复引用，补充成功反馈 |
| 状态反馈 | 搜索无匹配时缺少空态；键盘焦点被全局覆盖 | 区分无数据与无匹配，恢复可见焦点 |
| 主题一致性 | 导航与图表使用固定深色，缺少统一主题状态 | 共用主题变量和持久化偏好，图表跟随刷新 |
| 排版与密度 | 首页正文 14px 与共享界面 12px 不一致 | 恢复 12px 正文，统一间距与表面层次 |

实机补充：小组件内的字段配置被卡片裁切，移至共享抽屉并保留显式应用；中等宽度导航挤走功能标签，改为两行显示；指标详情在桌面窄窗口仍为单列，改为适配双列；指标包内部按钮的键盘事件冒泡会误触打开包，限制为卡片自身触发。

当前实机证据：`artifacts/ui-consistency-20261002/01-home-dark-before.png`、`02-library-before.png`。其他截图若仍为加载或错误状态不作为视觉结论证据。预览恢复后继续验证；尚未验证的页面和状态不标记通过。
