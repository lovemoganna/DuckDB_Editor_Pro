## 真实数据结果

使用已存在的 `sql_funds_flow` 数据，原业务表仍为 13 表、96 行，上传 SQL 版本 9。验收只新增工作台配置、保存查询和数据集定义，没有增删改业务记录。

- 所有状态按币种统计时，USD 合计 **114,470.00**，其他币种独立显示。
- 全局条件 `status = completed AND currency = USD`：金额 **104,270.00**，明细 **9 笔**，月趋势 **7 组**。
- 从相同金额来源重复放置一个实例，再添加局部条件 `amount >= 10000`：**97,000.00**；原实例仍为 **104,270.00**。
- 点击月趋势的一月柱形：日期范围 `[2025-01-01, 2025-02-01)`，金额 **50,000.00**、明细 **1 笔**。
- 独立订单库组件显示 **1,000**；资金状态、币种和时间条件没有任意套用到订单库。
- 原“资金业务总览”11 个组件正常加载，USD 完成金额 **104,270**、USDT 完成金额 **13,000**、完成率 **86%**、USD 净流入 **47,730**，未发现组件查询错误。

## 共同根因与修改边界

1. 共享数据集目录、筛选编译和运行时替代首页各组件分别拼接条件、限制源数据后分析的做法。
2. 实例展示覆盖保存在 DashboardItem；保留原指标/图表来源引用，重复放置不会互相修改。
3. 条件值通过 DuckDB 准备语句绑定。编辑器中的 SQL 追溯另生成正确转义的可执行副本，保留实际条件和明确来源。
4. 数值参数保留十进制字符串并按实际数据库类型 CAST，避免先转换 JavaScript 数值损失精度。
5. 依赖当前字段元数据校验数据集与条件；真实结果元数据决定日期显示，避免把 BIGINT 误当日期。
6. 可视化关联在创建和重新查询时检查右侧键唯一性。重复计量风险不会只在第一次保存时检查。
7. 保存布局与查询定义更新分开处理；保存布局只更新视图，不再触发整盘业务数据重算。
8. 继续复用 ActionButton、FormInput、FormSelect、ModalShell、原 ChartRenderer 与布局组件，未增加局部主题覆盖。
9. 旧 Dashboard 类型重复声明收敛；现有 workbench 后端类型契约保留，新分析契约独立放入 analysisTypes。

## 当前能力边界

这是本地 DuckDB 分析工作台的首个可用版本。以下没有以现有能力替代或宣称完成：

- 任意外部文件/远程系统的实时更新检测：需重新载入来源；定时查询只读取已连接数据。
- 任意 SQL 的可筛选性：逗号关联、未绑定位置参数、同名 CTE 遮蔽等复杂形态显式拒绝或标明不适用。建议转换为明确输出的结构化数据集或显式 JOIN。
- 聚合计算覆盖完整源数据；组件输出按每页 100 行展示。高基数组图显示当前页并提示，不把当前页图表称为完整分布；搜索、排序与 CSV 导出作用于当前页。
- 自定义 SQL 数据集的 WHERE 约束其输出关系；若 SQL 本身已聚合，它不等同于修改该 SQL 内部的源行条件。普通表/标准指标以及明确物理 FROM/JOIN 来源支持聚合前筛选。
- 联动为当前选择加默认/局部多条件；没有多联动组、多个同时叠加图表选择的完整管理界面。
- 复杂语义字段注册、单位映射、来源定义历史回滚、多步撤销是后续增强。表字段重命名会显式失效并要求重新绑定，不会自动猜测另一列。
- 业务修订事件目前使共享运行时缓存整体失效，尚未进一步精细到仅刷新每一张受影响表的所有依赖。
- 未接入数据库在重新打开持久库后需要重新附加；不会读取另一个同名数据源替代。
- 团队权限、云发布、服务端多用户仪表盘和多人协作在原批准规划中已列为另一个范围，当前未实现。

以上边界不阻碍目前已验证的“选数据、搭组件、编排、联动重算、保存继续编辑”闭环；也不代表已经达到商业 BI 平台全部企业能力。
