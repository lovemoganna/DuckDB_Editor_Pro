# 首页工作台行为契约

## 本轮范围

首页是当前数据库的分析工作台，不是系统监控，也不自动定义业务 KPI。
沿用现有数据发现、内容库、SQL 工作台、图表和布局持久化，不替换技术栈。

| 状态 | 首页主体 | 主要入口 |
| --- | --- | --- |
| 没有可用数据 | 导入状态；不伪造分析结果 | 导入数据 |
| 有数据，当前视图没有分析 | 开始分析、真实数据集 | 数据集明细、新建查询、添加已有分析 |
| 当前视图有分析 | 用户保存的组件与布局 | 筛选、来源、编辑布局、新建查询 |

刷新发现的内容只进入对象库。首次访问、清空视图、刷新均不自动添加组件。
切换数据库后，前一数据库的工作台不可继续展示或操作；同库刷新保留组件状态。
首页新建查询必须创建现用 SQL 工作台的空白页，不得修改旧查询页或自动运行伪造查询。

## 固定验收链

真实数据 → 首页选择数据集 → 新建查询 → 执行 → 图表 → 加入看板 →
返回首页 → 查看来源 → 筛选与清除 → 布局保存 → 刷新恢复 → 切库隔离。

业务测试限定币种，不以跨币种金额总和充当 KPI。已保存定义、用户布局和原始文件不得重写。
组件替身测试只证明状态契约，不替代真实浏览器数据验证。
