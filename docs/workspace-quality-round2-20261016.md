# 工作区品质提升 · 第二轮 · 2026-10-16

本轮从首次使用页扩展到真实分析工作区、可视化资产、全屏查看和首次加载体积。按照检查、修改、复核推进；不以获奖或全站认证作为自评结论。

## 已落实的改进

- 数据、Schema、SQL、历史、审计页面按进入时加载。首页不再因这些静态导入提前包含整个页面实现。
- 设置、导入、导出、备份和数据库管理工具首次打开时加载。`DeferredTool` 在首次打开后保留组件实例，关闭再打开不会因本次优化重建未保存的表单状态。加载过程中有可取消的反馈。
- ELK 布局引擎从模块初始化时构建，改为实际调用异步布局时加载并复用；力导向模式不调用该引擎。加载失败清除缓存，后续调用可重试。布局接口、算法和数据没有替换。
- 看板卡片直接展示全屏入口；全屏使用共享焦点管理，Tab 保持在窗口内，Escape 退出后返回触发按钮。
- 锁定看板隐藏拖拽把手，进入布局编辑才展示。卡片使用标题语义，数字层级和等宽数字排版更清晰。
- 图表绘图区支持键盘聚焦、原生方向键滚动；超出宽度时明确提示横向滚动。Canvas 提供标题与系列信息的可读名称。图表数据、格式和分类保持原有计算方式。
- 可视化资产卡片不再被同行的大图强制拉高，紧凑 KPI 保持自然高度；保留原有网格顺序。
- 首页元数据说明按完整短语换行，避免手机上解释文字只剩两字悬在末行。

## 性能体积比较

同一项目配置下，对比本轮修改前与最终生产构建，递归统计入口的静态 JavaScript 依赖图：

| 口径 | 修改前 | 最终 | 降幅 |
| --- | ---: | ---: | ---: |
| JavaScript 文件总字节 | 8,118,294 | 5,722,414 | 29.5% |
| 各文件 gzip 字节合计 | 2,115,063 | 1,440,397 | 31.9% |

这是构建依赖体积比较，不是网络传输实测、LCP、INP 或页面就绪时间。统计不含 CSS、字体、WASM 及之后按需加载的代码。主要依据是入口拆分与布局引擎延后加载；没有删除功能来缩小体积。

`bundle-before/report.json` 与 `bundle-final/report.json` 保存逐个 chunk 和主要模块的证据。新浏览器会话的网络资源记录也确认首次使用页没有请求 ImportWizard、WorkbenchView 或 ELK 的独立模块。

## 验证结果

- 相关单元/组件/布局测试：12 文件、555 项全部通过。包括延后加载前不调用工具、关闭后草稿保留、加载取消、布局模式与响应式布局、看板隔离、图例同步、请求竞争及共享图表等。
- 最终类型检查和生产构建通过。初次类型检查发现 ELK 默认导出是构造函数，已修正为 `InstanceType<typeof ELK>` 后重新验证。
- 浏览器：深浅主题、六种首次使用视口、真实看板、全屏焦点循环和焦点返回、手机图表键盘滚动通过，未捕获异常为 0。
- 通过实际全局导航加载 16 个业务入口：数据、Schema、SQL、数据流、指标、可视化、分析、历史、审计、知识资产、插件、知识联动、本体图谱、技能、能力、推演。分析截图等待实际透视结果，可视化截图等待图表出现；这些是入口和渲染检查，不代表穷尽每个模块的全部功能。
- 扩展真实看板回归：1/12/36 组件、两主题、五宽度；绘制、无重叠、保存布局不受窗口尺寸改写、全屏编辑保存重载、数据库切换、旧布局恢复、空结果与 SQL 错误隔离均通过。
- 最终生产构建的真实数据重放：四表 Excel 导入、日期无 1 毫秒漂移、USD 透视汇总 104,270、保存图表并加入首页、390px 图表左轴可达全部通过。生产首次使用的主题、视口和工具入口也通过。

测试中的 React 错误日志包含刻意破坏单个组件以验证错误边界的案例；以最终测试退出码和结果统计为准，不将预期错误日志当作运行页面故障。

## 证据与重放

- `home-regression/results.json`、`trace.zip`：扩展看板验收。

- `production-real-final/checks.json`、`trace.zip`：最终生产真实数据验收。

重放：使用项目已安装的依赖执行 `node scripts/verify-workspace-quality.mjs`；设置 `QUALITY_AUDIT_FEATURES=1` 增加业务入口检查，`QUALITY_OUTPUT` 指向新的证据目录。生产首次使用使用 `QUALITY_STATIC_ONLY=1`。真实生产验收使用 `scripts/test-funds-production.mjs` 和 `FUNDS_BASE_URL/FUNDS_OUTPUT`。构建体积用 `scripts/analyze-bundle.mjs`，通过 `QUALITY_BUNDLE_OUTPUT` 指定输出位置。

所有浏览器验收在独立上下文执行，没有改写用户当前浏览器的数据库。已有工作区改动保留；没有提交、推送或对外发布。

## 结论边界

本轮可复核的改进与回归通过。构建仍有大包、混合导入及 DuckDB worker eval 警告；加载体积降低不等于已达到性能指标。未完成 Safari/Firefox、真实手机、屏幕阅读器全面验收或所有模块的深入视觉与交互审查。奖项级别需要独立评审和更完整的产品体验证据，不能仅凭这些通过项宣称达标。
