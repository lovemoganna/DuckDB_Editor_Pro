## 可重复闭环

1. 启动本地预览，选择 `workbench_review_20261004`。
2. 打开 `资金副本验收-重开`：左关联数据集 `资金流水与用户`，金额、月度趋势、明细及同来源独立实例共 4 个组件。
3. 默认条件 `status = completed` 仅映射到此关联数据集。独立实例不参与全局筛选。
4. 点击趋势图一月节点，核对 3 条明细及三种币种金额；清除联动。
5. 解锁、拖拽、缩放，保存并锁定。重新加载后位置、大小、条件与实例配置恢复。
6. 在副本 SQL 修改一条流水金额，返回首页验证更新，再恢复原值。外部原文件不会自动被读取。
7. 管理视图复制为 `资金副本验收-复制`，修改其金额实例标题；原视图保持 `完成交易金额`。
8. `来源与异常验收` 保留空表、追加、已有指标、分页和缺失附加库的测试对象。附加库使用内存副本，重新加载后需要重新附加才可恢复该跨库组件。

## 扫描范围与证据边界

已通过实际导航进入首页、数据、Schema、SQL、数据流、指标、可视化、分析、历史、审计、知识资产、插件、本体图谱、技能、能力、推演。主要工作台流程、筛选、内容抽屉、实例和字段弹窗、返回路径有实际操作证据。子模块入口扫描不等于其全部业务功能验收；外部 AI、插件远程能力和所有高级图谱操作没有逐项端到端验收。

`route-width-audit.json` 覆盖 16 个入口 × 1440、1024、760、390 四种宽度；均未发现文档整体宽度溢出。长表格、画布及部分导航使用其自身横向滚动。深浅主题及 390 宽筛选弹窗实际检查，Tab 移动焦点、Escape 关闭并返回原入口通过。

## 仍缺少的能力及限制

- 外部文件变化不会自动重导入；已验证的方式为重新导入副本或手动重新连接。定时刷新只重查已连接数据。
- 审计记录仍在当前会话内，未实现覆盖全部 SQL 的持久审计。
- 任意 SQL 关联仍需作者确认关联基数；可视化关联会实际检查右侧唯一键。无法安全套用条件的 SQL 明确拒绝处理。
- 超过 100 组输出的图表只显示当前页并有提示；完整聚合已计算，未增加跨页绘图能力。
- 小窗口采用横向滚动画布，未新增按设备分别保存布局。
- 既有旧工作区的 OPFS 写入报错 `File is not opened in write mode` 没有通过破坏性重置修复。本次验收隔离库正常写入；旧库仍需另行诊断。
- 历史已导入的 Excel TIMESTAMPTZ 不会自动转换，需明确业务时区后重新导入或迁移。本次只重导入验收副本。
- 多联动组、多人协作、云发布没有加入本轮范围。AI 模板、配置项及按钮没有计为实际推理能力完成。
